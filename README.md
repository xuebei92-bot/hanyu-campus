# Hanyu Campus MVP

一个可本地运行的“线下国际中文课堂”MVP，纯前端实现，使用浏览器 localStorage 模拟后端数据层。

## 启动

直接双击 `index.html` 即可打开；也可以在此目录运行任意静态文件服务器。

## 演示账号

- 学生：`anna` / `hanyu123`
- 教师：`teacher` / `hanyu123`

## 已实现

- 学生/教师角色切换与演示数据
- 今日课程、课本词汇/课文/语法/音频入口、作业、练习、成绩
- 学生头像上传与更换（保存在浏览器本地）
- 动态签到码（15 秒刷新、5 分钟倒计时、单设备单账号限制）
- 教师手动调整签到、课堂控制、作业与成绩概览
- Quiz、Word Match、Sentence Order 最小可用活动
